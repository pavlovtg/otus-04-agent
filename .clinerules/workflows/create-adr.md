# Workflow: create-adr

## Шаги

1. Спросить у пользователя название решения (на русском).
2. Определить следующий номер: максимальный существующий номер в `docs/adr/README.md` + 1, с ведущим нулём (001, 002, ...).
3. Сформировать имя файла: `ADR-NNN-название-латиницей-через-дефис.md`.
4. Создать файл `docs/adr/ADR-NNN-название.md` по шаблону.
5. Добавить строку в `docs/adr/README.md`.

## Шаблон ADR

```markdown
# ADR-NNN: Название

- **Контекст**: одно предложение — почему встал вопрос.
- **Решение**: одно предложение — что выбрали.
```

## Правила

- Язык: русский.
- Одно предложение вместо абзаца.
- Убирать вводные фразы и дублирующие пояснения.
- Цель: экономия токенов контекста без потери смысла.
