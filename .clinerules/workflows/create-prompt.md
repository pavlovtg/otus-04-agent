# Workflow: create-prompt

## Шаги

1. Спросить у пользователя кодовое название промта (codename) на латинице через дефис.
2. Определить индекс: найти максимальный существующий индекс в `homework/prompts/`, прибавить 1, добавить ведущий ноль.
3. Сформировать имя файла: `<index>-<codename>.md`.
4. Создать файл в папке `homework/prompts/` с шаблоном промта.

## Шаблон промта

```markdown
# <Название промта>

## Роль

- <Кто выполняет задачу>.

## Контекст

- <Что известно о ситуации>.

## Задача

- <Что нужно сделать>.

## Требования

- <Ограничения и критерии результата>.
```
