# Memory Bank

- Memory bank находится в `/docs/ai/memory-bank/`.
- В начале каждой задачи читать все файлы memory bank для восстановления контекста.
- В конце каждой задачи обновлять `activeContext.md` и `progress.md`.
- Язык memory bank — русский.
- Файлы memory bank:
  - `projectbrief.md` — цель и суть проекта.
  - `productContext.md` — продуктовый контекст и требования.
  - `activeContext.md` — текущий этап, следующие шаги, открытые вопросы.
  - `systemPatterns.md` — архитектурные паттерны и структура проекта.
  - `techContext.md` — технологический стек и конфигурация.
  - `progress.md` — что сделано, в работе, не начато.
