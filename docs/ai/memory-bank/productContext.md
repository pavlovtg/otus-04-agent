# Product Context

- Домашнее задание курса OTUS: собрать и запустить минимального LangChain-агента.
- Агент работает как CLI-инструмент (`python main.py "<запрос>"`).
- Поддерживает 2–4 API-операции (создать / получить / обновить / список).
- Ответ агента — фиксированный контракт: Status / Action / Data / Errors.
- Секреты не коммитятся; в репозитории есть `.env.example`.
