# ADR-003: Code style для Python

- **Контекст**: необходимо зафиксировать единые правила оформления кода на Python для всех участников и AI-агента.
- **Решение**: использовать следующие правила:

## Именование

- Функции, переменные, модули — `snake_case`.
- Классы — `PascalCase`.
- Константы — `UPPER_SNAKE_CASE`.
- Приватные атрибуты — `_snake_case`.

## Форматирование

- Отступ — 4 пробела.
- Максимальная длина строки — 88 символов.
- Две пустые строки между функциями верхнего уровня и классами.
- Одна пустая строка между методами класса.

## Импорты

- Порядок: stdlib → сторонние → локальные, разделённые пустой строкой.
- Не использовать `from module import *`.

## Типизация

- Использовать аннотации типов (`def foo(x: int) -> str`).
- Для сложных типов — `from typing import ...`.

## Документация

- Docstring для публичных функций и классов.
- Комментарии — только для неочевидной логики.
