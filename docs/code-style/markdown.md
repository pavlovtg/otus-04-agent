# Markdown Code Style

## Заголовки

- Перед заголовком и после него — одна пустая строка (MD022).
- Исключение: заголовок в начале файла — пустая строка только после.

## Конец файла

- Файл должен заканчиваться одной пустой строкой (MD047).

## Пустые строки

- Не использовать несколько пустых строк подряд (MD012).
- Максимум одна последовательная пустая строка.

## Списки

- Перед списком и после него — одна пустая строка (MD032).
- Исключение: список в начале или конце файла.

## Ссылки

- Не использовать «голые» URL в тексте — оборачивать в `<>` или `[текст](url)` (MD034).
- Пример допустимого: `<https://example.com>` или `[Example](https://example.com)`.

## Пробелы

- Не оставлять пробелы в конце строк (MD009).
- Исключение: два пробела в конце строки для явного переноса (`<br>`).

## Общее

- Отступ в списках — 2 пробела.
- Использовать `-` для маркированных списков.
- Блоки кода — с указанием языка (` ```python `).
