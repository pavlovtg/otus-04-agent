# C# Code Style

## Именование

- Классы, методы, свойства — `PascalCase`.
- Локальные переменные, параметры — `camelCase`.
- Приватные поля — `_camelCase`.
- Константы — `PascalCase`.
- Интерфейсы — префикс `I` (`IService`).

## Форматирование

- Отступ — 4 пробела.
- Открывающая скобка `{` — на новой строке.
- Одна пустая строка между методами.
- Максимальная длина строки — 120 символов.

## Код

- `var` — только когда тип очевиден из правой части.
- Использовать `string.Empty` вместо `""`.
- Null-проверки через `??` и `?.`.
- `async/await` вместо `.Result`/`.Wait()`.
- Не использовать `public` поля — только свойства.

## Организация файла

- Порядок: поля → конструкторы → свойства → методы.
- Один класс — один файл.
- `using` — в начале файла, без лишних.
