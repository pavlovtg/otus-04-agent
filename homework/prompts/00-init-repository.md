# Инициализация репозитория для работы

## Роль

- Ты — разработчик, подготавливающий репозиторий для работы с AI-ассистентом Cline.

## Контекст

- Чистый репозиторий, ничего не настроено.
- В репозитории есть только файлы описывающие общую задачу.
- Проект без настроенных rules, skills, ignore.
- Проект без memory bank и без правил его использования.

## Задачи и требования

Настроить репозиторий для разработки вместе с AI-ассистентом Cline.

1. Язык взаимодействия с агентом и промтинга:
    - Язык взаимодействия c AI-агентом — русский;
    - Cline обязан отвечать **только на русском языке** во всех взаимодействиях, если иное не указано явно пользователем;
    - Создать правило для Cline 'language.md' с языком взаимодействия с агентом и промтинга;
2. Форма при создании промтов:
    - Структура разделов: Роль / Контекст / Задача / Требования.
    - Язык: русский.
    - Одно предложение вместо абзаца.
    - Убирать вводные фразы и дублирующие пояснения.
    - Цель: экономия токенов контекста без потери смысла.
    - Создать правило для Cline 'prompts.md' с правилом формата промтов;
3. Code style для C#:
    - Создать ADR-001 в `docs/adr/` с правилами code style для C#;
    - Зафиксировать базовые правила code style для C#;
    - Обновить индекс `docs/adr/README.md`;
    - Все создаваемые файлы максимально компактны: буллеты, одно предложение вместо абзаца, без вводных фраз;
    - Цель: экономия токенов контекста без потери смысла.
4. Code style для Markdown:
    - Создать ADR-002 в `docs/adr/` с правилами code style для Markdown;
    - Зафиксировать базовые правила code style для Markdown;
    - Зафиксировать правила из следующей документации:
        - <https://github.com/DavidAnson/markdownlint/blob/v0.40.0/doc/md022.md>
        - <https://github.com/DavidAnson/markdownlint/blob/v0.40.0/doc/md047.md>
        - <https://github.com/DavidAnson/markdownlint/blob/v0.40.0/doc/md012.md>
        - <https://github.com/DavidAnson/markdownlint/blob/v0.40.0/doc/md032.md>
        - <https://github.com/DavidAnson/markdownlint/blob/v0.40.0/doc/md034.md>
        - <https://github.com/DavidAnson/markdownlint/blob/v0.40.0/doc/md009.md>
    - Обновить индекс `docs/adr/README.md`;
    - Все создаваемые файлы максимально компактны: буллеты, одно предложение вместо абзаца, без вводных фраз;
    - Цель: экономия токенов контекста без потери смысла.
5. Code style для Python:
    - Создать ADR-003 в `docs/adr/` с правилами code style для Python;
    - Зафиксировать базовые правила code style для Python;
    - Обновить индекс `docs/adr/README.md`;
    - Все создаваемые файлы максимально компактны: буллеты, одно предложение вместо абзаца, без вводных фраз;
    - Цель: экономия токенов контекста без потери смысла.
6. Настроить правила Cline (`.clineignore`) так, чтобы агент игнорировал нерелевантные части проекта при обходе файловой системы и чтении контекста:
    - Создать файл `clineignore` с явным перечнем директорий и файлов, которые агент не должен читать без явного запроса пользователя.
    - Включить в список: результаты сборки проектов bin и obj, бинарные файлы (`*.snk`, `*.png`, `*.svg`).
    - Правило должно содержать обоснование (экономия токенов) и исключение (читать только по явному запросу).
    - Оформить файл согласно [.clineignore](https://docs.cline.bot/customization/clineignore).
7. Настроить memory bank:
    - Инициализировать memory bank командой `init memory bank in folder /docs/ai/memory-bank`;
    - Создать `.clinerules/memory-bank.md` — правило читать и обновлять memory bank при каждой задаче;
    - Memory bank на русском языке;
    - Все создаваемые файлы максимально компактны: буллеты, одно предложение вместо абзаца, без вводных фраз;
    - Цель: экономия токенов контекста без потери смысла.
8. Настроить workflow `create-prompt`:
    - Создать workflow `create-prompt` как файл `create-prompt.md` в папке `.clinerules/workflows/`.
    - Зафиксировать в workflow последовательность действий:
        - Спросить у пользователя кодовое название промта (codename);
        - Задать имя файла: `<index>-<codename>.md`, где `<index>` — максимальный существующий индекс + 1 с ведущим нулём, `<codename>` — краткое название латиницей через дефис, запрашивается у пользователя;
        - Создать файл промта в папке `homework/prompts/`;
        - Записать в файл шаблон промта.
    - Зафиксировать в workflow шаблон промта:
        - Язык: русский;
        - Одно предложение вместо абзаца;
        - Структура разделов: Роль / Контекст / Задача / Требования, один буллет-плейсхолдер в каждом;
        - Убирать вводные фразы и дублирующие пояснения;
        - Цель: экономия токенов контекста без потери смысла.
9. Настроить git:
    - Создать файл `.gitignore` в корневой папке проекта.
    - В файле `.gitignore` зафиксировать все файлы, которые не нужно отправлять в репозиторий.
10. Настроить систему ADR:
    - Создать папку `docs/adr/`.
    - Создать индексный файл `docs/adr/README.md` — одна строка на каждый ADR.
    - Создать правило для Cline `.clinerules/adr.md`:
        - В начале каждой задачи читать `docs/adr/README.md` (индекс).
        - При необходимости деталей — читать конкретный ADR-файл.
        - При принятии нового архитектурного решения — создавать ADR-файл и обновлять индекс.
        - При устаревании решения — удалять ADR-файл и строку из индекса.
        - Язык ADR — русский.
        - Правила написания: одно предложение вместо абзаца, без вводных фраз, цель — экономия токенов.
    - Создать workflow `create-adr` как файл `.clinerules/workflows/create-adr.md`:
        - Спросить у пользователя название решения.
        - Определить следующий номер из индекса (NNN с ведущим нулём).
        - Создать файл `docs/adr/ADR-NNN-название-латиницей.md` по шаблону.
        - Добавить строку в `docs/adr/README.md`.
    - Шаблон ADR (два поля):
        - `# ADR-NNN: Название`
        - `- **Контекст**: одно предложение.`
        - `- **Решение**: одно предложение.`
    - Все создаваемые файлы максимально компактны: буллеты, одно предложение вместо абзаца, без вводных фраз.
    - Цель: экономия токенов контекста без потери смысла.
